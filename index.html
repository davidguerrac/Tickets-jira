🔄 Sincronización entre dispositivos

Usa un Gist privado de GitHub como almacén compartido. Configura esto en cada dispositivo (PC y celular) con el mismo token y mismo Gist ID para que los datos se sincronicen automáticamente.

Sin conectar
¿Cómo obtengo el token?
  1. Entra a GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate new token (classic) → marca solo el scope gist
  3. Copia el token (empieza con ghp_) y pégalo aquí
  4. Deja "Gist ID" vacío y presiona "Conectar" → se crea el Gist automáticamente
  5. Copia el Gist ID que aparece y úsalo en tu otro dispositivo (junto con el mismo token)
